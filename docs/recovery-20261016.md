## 3. Orion：保留旧 HEAD，只更新方法仓库

**要求队列没有你的任务、没有旧 watcher、tracked files 干净。** 下面的检查不通过就停止，不会取消作业。`~/IMTS` 的训练代码和环境保持不变。

```bash
(
  set -e
  cd ~/IMTS-method

  imts_queued_jobs="$(squeue -h -r -u "$USER" -o %i)"
  if [ -n "$imts_queued_jobs" ]; then
    printf '还有 Slurm 任务，先不要更新代码：\n%s\n' "$imts_queued_jobs"
    exit 1
  fi
  if pgrep -af '[s]cripts/submit_(benchmarks|parallel_baselines|method_pilot)\.py.*--submit.*--watch'; then
    echo '还有 watcher，先核对后再更新。'
    exit 1
  fi
  if ! git diff --quiet || ! git diff --cached --quiet; then
    echo '存在未提交的 tracked 改动，先核对；没有覆盖代码。'
    git status --short
    exit 1
  fi

  git fetch origin our-method
  git branch "backup/before-recovery-$(date +%Y%m%d-%H%M%S)" HEAD
  git switch -C our-method FETCH_HEAD
  git branch --set-upstream-to=origin/our-method our-method
)
```

这里不用 `git pull`：服务器旧提交与 Mac 重新提交后的历史不同，先备份旧 HEAD，再切换到已审核并 push 的新分支。原有 results 文件保留。
